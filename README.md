# ❄️ Frostbound

*A little frozen world, brought to life with code.*

🔗 **[Explore Frostbound Live](https://frostbound-six.vercel.app/)**

Frostbound is an interactive 3D ice castle experience built with Three.js. Step into a crystalline winter kingdom, explore its snowy surroundings, and discover the castle from two different perspectives.

### Features

- **Visitor View** — Experience the castle from up close.
- **Diorama View** — Admire the frozen kingdom as a miniature 3D world.
- **Snow Effects** — Bring the winter landscape to life.
- **Aurora Effects** — Add a touch of magic to the night sky.

### Built With

React · TypeScript · Three.js · React Three Fiber · Vite

### Run Locally

```bash
git clone https://github.com/khushik-4/FROSTBOUND.git
cd FROSTBOUND
npm install
npm run dev
```
